    Enable voice-controlled actions in your applications and devices for enhanced user experience.

    <CodeGroup tabs="JavaScript,Python">
      ```javascript
const voiceAgent = new VaibrixVoiceAgent({
  apiKey: 'your_api_key',
  language: 'en-US',
  wakeWord: 'Hey Assistant'
});

voiceAgent.onCommand('turn on lights', () => {
  // Execute light control logic
  console.log('Lights activated');
});

voiceAgent.startListening();
```
      ```python
from vaibrix_voice import VoiceAgent

agent = VoiceAgent(
    api_key='your_api_key',
    language='en-US',
    wake_word='Hey Assistant'
)

@agent.command('turn on lights')
def activate_lights():
    print('Lights activated')

agent.start_listening()
```
